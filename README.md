### Temel Özellikler

| Özellik | Detay |
| :--- | :--- |
| **Otomatik Planlama Motoru** | Ana iş parçacığını (Main Thread) dondurmadan, arkaplanda `Web Worker` kullanarak saniyeler içinde adil ve eksiksiz vardiya dağıtımı yapar. |
| **Dokunsal Sürükle-Bırak (DnD)** | `@dnd-kit/core` entegrasyonu ile saat kartlarını takvim üzerinde pürüzsüzce kaydırın, değiştirin ve kilitleyin. |
| **Kalıcı Veri (Persistence)** | `Zustand` ve `LocalStorage` mimarisi sayesinde oluşturulan takvimler, sayfayı yenileseniz dahi asla kaybolmaz. |
| **Kusursuz Tema Geçişi** | Saf CSS mantığı ve donanım ivmeli (GPU) geçişler ile Dark/Light mod arasında ipeksi ve senkronize renk uyumu. |
| **Premium Arayüz (Glassmorphism)** | Vercel ve Linear tasarım dillerinden ilham alınan "Yüzen Ada" (Floating Island) konsepti, Aurora arkaplanı ve donanım ivmeli animasyonlar. |

<br/>

---
### Geliştirme Felsefesi
* **Performans İlk Sırada:** Optimizasyon motoru için Web Workers kullanılarak UI kilitlenmelerinin önüne geçildi. Next.js Static Generation ile sayfa yükleme süreleri milisaniyelere indirildi.
* **Maliyet Odaklı Tasarım (Cost-Killer):** Sunucu tarafı render (SSR) yerine Client-Side Compute kullanılarak sıfır sunucu (backend) maliyeti hedeflendi.
* **Modern CSS Mimarisi:** Tailwind CSS v4 ile karmaşık yapılandırma dosyaları yok edildi, animasyonlar saf CSS keyframe'leri ile optimize edildi.

### Yerel Kurulum

Projeyi kendi bilgisayarınızda çalıştırmak ve test etmek için aşağıdaki adımları izleyin:

```bash
# Depoyu bilgisayarınıza klonlayın
git clone [https://github.com/Onur-Aba/chrono-shift.git](https://github.com/Onur-Aba/chrono-shift.git)

# Proje dizinine geçiş yapın
cd chrono-shift

# Gerekli bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev
```
